# Agentic OPA Guardrails 🛡️🤖

> **Declarative Security & Infrastructure Policy Engine for AI Agent Tool Execution**

A serverless, low-latency control plane that enforces deterministic security boundaries on autonomous AI agent execution loops. By compiling Open Policy Agent (OPA) Rego policies into WebAssembly (Wasm) and embedding them into a Python AWS Lambda runtime, this system dynamically blocks hallucinated or out-of-bounds agent tool executions based on real-time infrastructure state and telemetry.
